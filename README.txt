------------------------------------------------------------
1. ¿QUÉ ES ÚTILHUB?
------------------------------------------------------------

ÚtilHub es un sitio web de herramientas prácticas diseñado
para reunir diferentes utilidades en un solo lugar.

Incluye herramientas de:

- Cálculo
- Conversiones
- Tiempo
- Texto
- Organización
- Productividad
- Compras
- Comida
- Entretenimiento
- Utilidades generales

ÚtilHub funciona sin inteligencia artificial.

------------------------------------------------------------
2. NOVA FLOW
------------------------------------------------------------

NOVA FLOW NO es el nombre del sitio.

NOVA FLOW es el sistema de animaciones visuales de ÚtilHub.

V25 incluye 120 modos de animación diferentes.

Las animaciones están diseñadas para funcionar mediante un
canvas global que permanece visible detrás de todo el sitio.

Esto permite que NOVA FLOW pueda verse mientras el usuario:

- Está en el inicio.
- Busca herramientas.
- Abre una herramienta.
- Se desplaza por la página.
- Utiliza las funciones de productividad.
- Cambia de sección.

Las animaciones se controlan desde un único menú.

5. DICCIONARIO
------------------------------------------------------------

El diccionario fue eliminado en V25.

No forma parte de las herramientas principales de esta
versión porque la función anterior no funcionaba
correctamente.

------------------------------------------------------------
6. INTELIGENCIA ARTIFICIAL
------------------------------------------------------------

ÚtilHub V25 NO utiliza inteligencia artificial.

Las herramientas funcionan mediante JavaScript, APIs
externas cuando son necesarias y almacenamiento local.

------------------------------------------------------------
7. COMIDA Y COMPRAS
------------------------------------------------------------

ÚtilHub permite acceder a búsquedas y recursos relacionados
con comida y compras.

ÚtilHub NO realiza pedidos automáticamente.

El usuario debe realizar personalmente cualquier pedido,
compra, pago o confirmación en el sitio correspondiente.

ÚtilHub tampoco garantiza precios, disponibilidad o tiempos
de entrega de servicios externos.

------------------------------------------------------------
8. PWA
------------------------------------------------------------

ÚtilHub V25 está preparado para funcionar como una
Progressive Web App (PWA).

Archivos relacionados:

- manifest.webmanifest
- sw.js

Esto permite que el sitio pueda instalarse como una
aplicación cuando el navegador y la plataforma lo permitan.

------------------------------------------------------------
9. ICONO
------------------------------------------------------------

El icono principal de ÚtilHub está integrado directamente
en el código de la página.

No es necesario utilizar un archivo externo como:

- icon.png
- icon.jpg
- icon.svg

El objetivo es mantener el diseño del proyecto dentro de
los propios archivos de código.

------------------------------------------------------------
10. GUARDADO LOCAL
------------------------------------------------------------

ÚtilHub utiliza almacenamiento local del navegador para
guardar determinadas preferencias y datos.

Puede guardar elementos como:

- Tema
- Herramientas favoritas
- Herramientas recientes
- Notas
- Tareas
- Lista de compras
- Configuración de NOVA FLOW
- Preferencias de rendimiento

Estos datos pertenecen al navegador y dispositivo donde
se utilizan.

------------------------------------------------------------
11. MODOS DE RENDIMIENTO
------------------------------------------------------------

NOVA FLOW puede adaptar su funcionamiento mediante
diferentes niveles de rendimiento:

- Auto
- Alto
- Equilibrado
- Rendimiento
- Ahorro

Esto permite reducir el uso de recursos en dispositivos
menos potentes.

------------------------------------------------------------
12. MODO MOVIMIENTO
------------------------------------------------------------

ÚtilHub permite activar o desactivar los efectos de
movimiento.

También se tienen en cuenta las preferencias de reducción
de movimiento del sistema operativo o navegador.

------------------------------------------------------------
14. INSTALACIÓN EN GITHUB
------------------------------------------------------------

1. Crear un repositorio en GitHub.

2. Subir todos los archivos del proyecto.

3. Verificar que los nombres sean exactamente:

   index.html
   style.css
   script.js
   manifest.webmanifest
   sw.js
   README.txt

4. Activar GitHub Pages.

5. Seleccionar la rama principal y la carpeta raíz.

6. Guardar la configuración.

7. Abrir la dirección proporcionada por GitHub Pages.

------------------------------------------------------------
15. ACTUALIZACIÓN
------------------------------------------------------------

Cuando se publique una nueva versión:

1. Actualizar los archivos del proyecto.
2. Cambiar la versión del Service Worker.
3. Subir los archivos nuevos a GitHub.
4. Recargar el sitio.
5. Si el navegador mantiene una versión antigua,
   cerrar y volver a abrir la aplicación.

El Service Worker de V25 utiliza:

utilhub-v25-nova-flow-v1

------------------------------------------------------------
16. PRIVACIDAD
------------------------------------------------------------

Los datos guardados mediante almacenamiento local
permanecen en el navegador del usuario.

Las herramientas que utilizan servicios externos pueden
enviar la información necesaria a dichos servicios.

No introducir información privada o sensible en servicios
externos.

------------------------------------------------------------
17. OBJETIVO DE V25
------------------------------------------------------------

El objetivo de ÚtilHub V25 es reunir herramientas útiles
en una interfaz sencilla, rápida y organizada.

NOVA FLOW proporciona la experiencia visual mediante
animaciones globales sin convertirse en el nombre del
proyecto.
